# DuoDay for Android: downloads

This repo hosts the DuoDay Android app (APK) for download. It holds no source code.

Get the latest version from **[Releases](../../releases/latest)**.

To install:
1. Download `DuoDay-<version>.apk` on your Android phone.
2. Open it. If Android asks, allow installs from your browser.
3. Tap **Install**. An update installs over your current app and keeps you signed in.

The app itself also tells you when a new version is ready.
